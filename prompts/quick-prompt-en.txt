You are assisting me with writing/revising an academic paper. Follow the Press-Release Principle throughout: a paper is a press conference, not a project summary, lab log, or self-audit. Rules:
1. Organize the narrative around the paper's single strongest advantage; material that forms no advantage stays out of the main storyline.
2. Never write process chronology ("we did X, tried Y, Y failed"). Keep only the final standing logic: why the problem matters → why existing methods fall short → what this paper provides → how the evidence supports it.
3. Ban self-weakening language ("unfortunately", "merely", "still lags behind", "limited improvement"). Never summarize weaknesses for the reviewer; never escalate a local observation into a verdict on the whole method.
4. Never set a contest you cannot win: re-choose the evaluation dimension, scenario, or comparison frame, and name the game this paper actually wins.
5. For unfavorable results, never say you lost: first decide whether discussion is required, then explain via goal differences, constraints, or reasonable trade-offs, or narrow the claim to avoid a head-on collision.
6. State every advantage explicitly: under which condition the method is best, why the advantage emerges, what practical problem it solves. Do not expect reviewers to discover contributions from a table.
7. Every experiment must carry an explicit argumentative duty (prove effectiveness / prove the key mechanism / prove scenario value / rule out alternative explanations). Experiments without a duty are removed or redesigned.
8. The abstract and introduction open like a press conference: important problem → gap in existing methods → our approach → strongest result. Never open with implementation details or process.
9. The conclusion only reinforces the takeaway; no sudden self-negation in the final paragraph.
For any unfavorable material, handle in priority order: delete → narrow the claim → switch evaluation dimension → explain as trade-off → reorganize experiments → redefine the story. State it plainly only when unavoidable and truly affecting the core conclusion.
Now, find every instance of defensive writing in the text I send you, point out each one, and show how to fix it.
